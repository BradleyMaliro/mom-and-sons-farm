# Mother &amp; Sons Farm Website

A mobile-first website for Mother &amp; Sons Farm in Kitale, Kenya. Customers can browse farm products, filter by category, and order instantly through WhatsApp.

## Why I built it

Most customers in Kenya already order through WhatsApp, so the site is built around that: see a product, tap one button, and a chat opens with the order message already written.

## Features

- Product catalogue built from a JavaScript data list, so prices and items are easy to update
- Category filters (Poultry, Livestock, Dairy & Eggs, Farm Produce, Farm Supplies)
- One-tap WhatsApp ordering with a pre-filled message
- Mobile-first responsive layout
- Delivery and contact information

## Built with

- HTML5
- CSS3 (Flexbox, Grid, custom properties)
- Vanilla JavaScript

## What I learned

- Structuring a project with semantic HTML
- Rendering content from data with JavaScript
- Building interactive filters using array methods
- Version control with Git and GitHub

## Run it locally

1. Clone the repository
2. Open the folder in VS Code
3. Right-click `index.html` and choose "Open with Live Server"
